# Security Policy

## Supported versions

Only the latest release (`ytxp@X.Y.Z`, see [Releases](https://github.com/glhrmbg/yt-experience/releases))
and the current `main` branch are supported. There are no older maintained branches.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/glhrmbg/yt-experience/security).
2. Click **Report a vulnerability**.

This opens a private advisory visible only to you and the maintainer, so details can be discussed
and fixed before anything is public.

This is a solo-maintained personal project - there's no bug bounty, but reports are taken
seriously and a fix (or at least an acknowledgment) should follow within a few days.
